# Футбол Аналітика

PWA-додаток для телефона (Android/iPhone): аналіз команд 15 чемпіонатів і трьох єврокубків (ЛЧ, ЛЄ, ЛК) і рекомендовані ставки на матчі.

## Запуск

- **Онлайн (телефон, будь-де):** https://calderone240591-cmyk.github.io/football-predictor/ → у Safari «Поділитися» → «На початковий екран».
- **Ноутбук:** двічі клацнути `start.bat` → відкриється http://localhost:8080.
- **Айфон у тій самій Wi-Fi:** Safari → адреса, яку показує вікно `start.bat` (наприклад http://192.168.0.105:8080) → «Поділитися» → «На початковий екран».
  Потрібне правило брандмауера Windows для порту 8080 (або профіль мережі «Приватна»).
- **Постійно, без ноутбука:** викласти папку на HTTPS-хостинг (наприклад, https://app.netlify.com/drop) і додати на початковий екран з того адресу.

Ключі й реєстрація не потрібні.

## Дані

ESPN (неофіційний публічний API, `site.web.api.espn.com` і `sports.core.api.espn.com`): розклад, результати, таблиці,
стартові склади, коефіцієнти DraftKings на 1X2 і тотал, сезонна статистика команд (xG, кутові, картки, удари, фоли).
Даних про травми там немає; їх частково враховують коефіцієнти букмекера.
Української Прем'єр-ліги та Швейцарії в ESPN немає, тому в списку Греція і Данія.

Список турнірів — `js/config.js`.

## Модель (`js/model.js`)

1. Індекси атаки й оборони з результатів сезону з урахуванням сили суперників; свіжі матчі важать більше
   (період напіврозпаду 120 днів), минулий сезон теж враховується з меншою вагою.
2. Єврокубки: стартова оцінка — рейтинг у чемпіонаті з поправкою на силу чемпіонату.
3. Де є xG (АПЛ, Ла Ліга, Серія A, Бундесліга, Ліга 1, Чемпіоншип, Бразилія), він входить у рейтинги на 40%.
   Пуассон з поправкою Діксона–Коулза → ймовірності рахунків і ~90 ринків: результат, тотали, фори, індивідуальні
   тотали, «обидві заб'ють», кількість голів, комбіновані, тайми, «тайм/матч», кутові, жовті картки
   (кутові й картки — від'ємний біноміальний розподіл за сезонною статистикою).
4. Якщо є коефіцієнти: 30% модель + 70% ринок (без маржі).
5. Основна ставка — найімовірніший ринок зі справедливим кф ≥ 1.30; «цінна» — перевага над кф ≥ 3% при ймовірності ≥ 30%.

Вкладка «Історія» (`js/history.js`) запам'ятовує передматчеві прогнози і після матчів рахує реальну влучність і прибуток цінних ставок.

Бектест (588 матчів за 45 днів, лише статистична частина): основна ставка влучила у 68.5% випадків, Brier 1X2 0.607.

Прогнози ймовірнісні та не гарантують виграшу. 18+.
